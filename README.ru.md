# Iskra (Искра)

[English](README.md) | **Русский** | [한국어](README.ko.md)

![Iskra mascot](assets/iskra-mascot.gif)

**Лёгкий персональный ИИ-агент, написанный с нуля на Rust.**
*Искра* — это та самая маленькая искра, с которой всё начинается.

Iskra — персональный агент, который живёт в мессенджере, помнит после перезапусков, использует инструменты в строгих границах разрешений и спроектирован так, чтобы его можно было разбирать и собирать заново: модель, канал или инструменты меняются без изменения ядра.

> **Статус:** v1 в активной разработке. Терминальный цикл ядра, файловые инструменты и память уже работают; следующий шаг — канал Telegram.
> В этом репозитории только код — личная память, данные и секреты здесь никогда не хранятся.

## Принципы проектирования

1. **Лёгкость по бюджету, а не по надежде** — один бинарный файл с жёсткими лимитами на размер, память в простое и число зависимостей; измерения на каждом релизе.
2. **Модульность по контрактам** — мозг, канал, инструменты и память соединяются версионированными спецификациями интерфейсов (`brain/v1`, `channel/v1`, `tool/v1`, `memory/v1`). Расширение — это добавление частей, а не правка ядра.
3. **Безопасность fail-closed** — инструменты работают внутри папки-песочницы, доступ к shell только по белому списку, секреты структурно не попадают в логи и память, а необратимые действия требуют одобрения человека.
4. **Дисциплина затрат** — повторяющаяся работа кристаллизуется в процедуры, которые выполняются без вызова модели; дорогие чувства (экран) — последнее средство, сначала структурированные каналы (API · DOM).
5. **Память, которую можно читать** — долговременная память — обычный Markdown с бюджетом загрузки, маскированием секретов при сохранении и защитой от заражения: внешний контент не попадает в основную память без проверки владельца.

## Текущее состояние (v1)

- [x] Скелет на Rust + мозг (прямые HTTP-запросы, без SDK) — модель сменная, в v1 по умолчанию DeepSeek
- [x] Цикл диалога с условиями остановки (лимит кругов инструментов, остановка при повторяющейся ошибке)
- [x] Файловые инструменты (`read_file`, `write_file`), ограниченные папкой `workspace/`
- [x] Память в Markdown с бюджетной загрузкой и маскируемым сохранением, файлы идентичности (SOUL.md / USER.md)
- [ ] Канал Telegram с белым списком отправителей
- [ ] Инструмент shell по белому списку + проверенная задача по программированию

## Дорожная карта

| Версия | Направление |
|---|---|
| v1 | Персональный агент для одного пользователя (Telegram, один мозг, четыре инструмента, память в Markdown) |
| v2 | Сменные части — формализация контрактов, несколько мозгов, маршрутизация через модель решений |
| v3 | Делегированная работа — триггеры, пакеты ботов, спецификация идентичности (`identity/v1`) |
| v4 | Настольное приложение (Tauri) — мультиботы, управление компьютером за воротами одобрения |
| v5 | Продукт — хостинговый режим, память и адаптеры по пользователям, подписанные релизы |

## Быстрый старт

```bash
git clone https://github.com/jeonghoheo/iskra.git
cd iskra
cp .env.example .env   # добавьте ключ API модели (по умолчанию в v1 — DeepSeek: DEEPSEEK_API_KEY)
cargo run
```
