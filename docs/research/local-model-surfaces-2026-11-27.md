# 로컬 모델 표면 5개 — Iskra 적용 후보 (2026-11-27)

상태: **가설.** 조사는 Hugging Face 트렌딩·모델 카드 기준이며, 한국어 품질·지연·RSS는 **미측정**이다. 수치와 모델명은 실측 전까지 사실로 인용하지 않는다. 결정의 정본은 `DECISIONS.md` 2026-11-27(음성 입력 어댑터 선행)이다.

## 공통 원칙

- 로컬이라서 이기는 경우만 채택한다: 프라이버시, 지연, 오프라인, 데이터 중력.
- 모델은 **별도 프로세스/형제 바이너리**로 둔다. Iskra 본체의 단일 바이너리·의존성 예산(직접 15개, strip 20MB, 유휴 RSS 30MB)을 침범하지 않는다.
- 값을 알 수 없으면 `unknown`. 추정으로 채우지 않는다(T4).
- 모델 라이선스는 별도 확인 대상이다. 아래 "확인" 표시가 없는 항목은 제품화 전에 카드 원문을 확인한다.

## 1. kiosk 음성 입출력

- 입력: Parakeet TDT 0.6B v3(CC-BY-4.0) 또는 Qwen3-ASR 0.6B(Apache-2.0).
- 출력: Kokoro-82M 또는 phonon-40m-multilingual(라이선스 미확인).
- 의도 분류: Liquid d1-2B(license: other).
- 왜 로컬: 마이크 데이터가 기기를 떠나지 않고, 발화 종료 지연이 0에 가깝다.
- 측정: 발화 종료→텍스트 p50/p95, 텍스트→첫 음성 p50/p95, 유휴 RSS, 한국어 CER.
- 중단: p95 1.5초 초과 또는 CER 15% 초과면 모델을 교체하고, 같은 접근이 2회 실패하면 접근을 바꾼다.
- 비고: Iskra는 이 경로를 **Hex 설치형 어댑터**로 먼저 검증한다. 자체 파이프라인은 `DECISIONS.md`의 트리거 충족 후 별도 카드다.

## 2. 화면 → 지시

- 캡처 → GLM-OCR(MIT) 또는 OCRia-nano-1(ONNX/CPU, license: other).
- 이해: Qwen3-VL-2B(Apache-2.0) 또는 d1-2B.
- 왜 로컬: 화면은 외부로 보낼 수 없다.
- 증거: 원본 캡처 해시 + OCR 텍스트 해시를 함께 남긴다. 모델이 본 것을 추정으로 재구성하지 않는다.
- 측정: 캡처→프롬프트 p95, OCR 오인식률, 토큰 절감.

## 3. 감사 증거 검색

- 임베딩: bge-m3-korean(MIT 계열) 또는 embeddinggemma-2(Apache-2.0, 멀티모달).
- 리랭커: hs-rerank-1(MIT) 또는 multilingual-reranker-small(Apache-2.0).
- 왜 로컬: 고객 로그가 밖으로 나가면 감사 상품 자체가 성립하지 않는다.
- 용도: "이 사고와 유사한 과거 사례 5건 + 원문 인용".
- 중단: 감사 3회 연속 서로 다른 맞춤 분석이 필요하면 고정 오퍼를 중단한다(생존 전략 §9).

## 4. 문서 증거 추출

- NuExtract3(Qwen3.5-4B, Apache-2.0)로 문서→JSON.
- 왜 로컬: 계약·양식 원문을 보호한다.
- 증거: 입력 파일 해시 + 추출 JSON 해시 + 모델 id.
- 측정: 필드 정확도, 처리 시간, 실패 시 `unknown` 유지.

## 5. 라우팅 / 판단

- EdgeCoder-Multilingual-61M(Apache-2.0) 또는 d1-2B.
- 왜 로컬: 호출 비용 0, ms 단위 지연, 요청 내용이 밖으로 나가지 않는다.
- 용도: "이 요청은 어느 에이전트/모델/도구인가".
- 측정: 라우팅 정확도, 오분류 시 폴백 경로.

## 하지 않는 것

- Hex 앱 클론, Rune 포크, 코어에 ASR 크레이트 링크.
- 범용 로컬 챗/코딩 어시스턴트.
- 개인 메모 자동 기록(정본 규칙 위반).
- 실시간 번역(품질 리스크가 데모를 죽인다).
