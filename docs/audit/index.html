What is needed

No. This is a fixed-scope diagnosis delivered through the existing Iskra audit path. It is not a runtime migration offer. Herdr-specific compatibility is claimed only after the relevant incident is actually reproduced.

Is this a full agent security audit?

No. It covers one restart duplicate-execution or duplicate-delivery incident only.

What if the incident cannot be reproduced?

The report distinguishes observed facts, failed reproduction attempts, and unresolved unknowns. It does not turn an unconfirmed report into a claimed fix.
